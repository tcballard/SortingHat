# Sorting Hat 0.2.0

- Build: 8
- Channels: Developer ID download and Homebrew; Mac App Store deferred

Sorting Hat 0.2.0 makes its plain-English filing rules predictable enough to
inspect and teach. Dynamic folders are now compiled into a controlled contract,
new rules can be previewed against real files without moving them, and a manual
correction can propose a reusable rule without silently changing the ruleset.

## What is new

- Route files with controlled destination values including merchant, client,
  project, source app, year, month, and year-month.
- Preview up to eight representative files before activating a ruleset. Each
  preview shows the matched rule, proposed filename, rendered destination,
  Finder tags, and whether the file needs review.
- Turn a one-off manual correction into an editable rule proposal. Adding the
  proposal remains an explicit action.
- Detect duplicate routes, subject conflicts, broader or narrower overlaps,
  unreachable rules after a catch-all, and attempts to add a second catch-all.
- Keep files in review when a controlled value is missing, uncertain,
  undeclared, or shaped like a filesystem path.

## Safety and verification

- Destination values are rendered only as whole validated path components
  beneath the configured output root.
- Preview uses the shipping extraction, routing, collision, and validation path
  while skipping file moves and Finder-tag writes.
- The merged v0.2 acceptance pass completed with 94 Swift tests, including 16
  focused rule-contract tests, and a successful `SortingHatApp` product build.
- The shipping-path structured-destination evaluation retained zero unsafe or
  invalid final decisions.

## Distribution

The direct-download release is Developer ID signed, notarized, stapled, and
published as a ZIP and drag-to-Applications DMG with a signed Sparkle appcast.
The published release workflow verifies the final artifacts before updating the
Homebrew cask.

Mac App Store work remains deliberately deferred in
[Issue #29](https://github.com/tcballard/SortingHat/issues/29) and does not block
this release.
